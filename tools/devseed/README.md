# devseed — ข้อมูลทดสอบสำหรับเว็บและแอป

สร้างใบเสนอราคาครบทุกสถานะที่ต้องใช้ทดสอบ **ผ่าน API จริง** ไม่ใช่ INSERT ตรงเข้า DB
กฎธุรกิจทุกข้อจึงถูกบังคับเหมือนที่ผู้ใช้จริงเจอ (validate ก่อนส่ง · versioning · ลายเซ็นผูกเวอร์ชัน)

## ใช้งาน

ต้องต่อ VPN และรัน API ก่อน

```bash
cd tools/devseed
dotnet run                          # สาขา 105 · API localhost:5080
dotnet run -- --branch 30           # สาขาอื่น (ต้องมีแคตตาล็อกในสาขานั้น)
dotnet run -- --api http://localhost:5081
```

อ่าน connection string จาก **user-secrets ตัวเดียวกับ API** (`UserSecretsId` ตรงกัน) ไม่ต้องตั้งค่าเพิ่ม

## สร้างอะไรให้

| สถานะ | ใช้ทดสอบ |
|---|---|
| ฉบับร่าง | หน้าแก้ไข 3 พาเนลบนเว็บ — แก้บรรทัด เพิ่ม/ลบ ส่งให้ลูกค้า |
| ส่งให้ลูกค้าแล้ว | คิวในแอปมือถือ — อนุมัติรายบรรทัดและเซ็น |
| อนุมัติบางส่วน + เซ็นแล้ว | หน้าเอกสาร — ผลอนุมัติรายบรรทัด สองบล็อกยอด รูปลายเซ็น |
| ฉบับแก้ไข v2 (ฉบับเดิมถูกแทนที่) | versioning — การอนุมัติเดิมเป็นโมฆะ ทุกบรรทัดกลับเป็นรออนุมัติ |

แต่ละใบมี 5 บรรทัด แยกกลุ่ม "ลูกค้าขอ" / "ช่างแนะนำ" มีทั้งค่าแรงและอะไหล่ และมีบรรทัดที่ใส่ส่วนลด 5%

## ข้อจำกัด

- **สาขาต้องมีแคตตาล็อกก่อน** — `DevSeed.cs` ของ API seed ไว้ที่สาขา 105 เท่านั้น
  สาขาอื่นต้องแก้ `BranchId` ในไฟล์นั้นแล้วรีสตาร์ท API (มันข้าม seed ถ้ามีข้อมูลแล้ว)
- ใช้งานว่างที่ยังไม่มีใบเสนอราคา ต้องมีอย่างน้อย 4 งาน
- ลายเซ็นเป็น PNG 1×1 — พอสำหรับทดสอบเส้นทางอัปโหลด/แสดงรูป ไม่ใช่ลายเซ็นจริง
