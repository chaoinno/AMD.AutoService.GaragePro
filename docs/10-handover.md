## 2. เรื่องที่ยังไม่ตัดสินใจ (ค้างอยู่จริง ไม่ใช่ของเก่า)

### 2.1 dev กับ production ใช้ฐานข้อมูลตัวเดียวกัน ⚠️
ทั้งสองฝั่งชี้ไป `10.10.4.11 / GarageService` เหมือนกันเป๊ะ แปลว่า:
- ใครรัน `dotnet ef database update` จากเครื่อง dev **มีผลกับ API ที่ลูกค้าใช้อยู่ทันที**
- ข้อมูลที่สร้างตอนทดสอบเป็นแถวจริงใน production (สาขา 227 "Service Center Demo")
- ที่ผ่านมารอดมาได้เพราะ migration ทุกตัวเป็น **additive ล้วน** (ตารางใหม่ / คอลัมน์ nullable)
  **ถ้าวันไหนมี migration ที่ drop หรือ rename ของจริง ระบบจะพังทันทีโดยไม่ต้อง deploy อะไรเลย**

→ ต้องเลือกสักทาง: แยกฐาน dev ออกมา **หรือ** ตั้งกติกาว่าใครรัน migration ได้ตอนไหน

### 2.2 ต้องบอกหน้าร้านเรื่องลำดับ "จ่ายเงิน → ออกใบเสร็จ → เซ็นรับรถ"
กฎข้อ 1 ในหัวข้อ 1 มีผลบน production แล้ว **แต่ยังไม่ได้แจ้งผู้ใช้**

### 2.3 RBAC ของ Job/Intake endpoint ยังเปิดกว้าง
ตอนนี้ gate ด้วย `[RequireShiftSession]` อย่างเดียว — ใครก็ตามที่ login แล้วมีกะเปิดอยู่
สร้าง/เปลี่ยนสถานะจ๊อบได้หมด **ต้องปิดก่อนขยายวงผู้ใช้** (โมดูลจับเวลา/จัดซื้อ/รายงาน
ไม่ได้สืบทอดช่องนี้ เพราะ gate role ที่ service ทุกเมธอด)

## 4. กับดักที่ทำให้เสียเวลาไปแล้วจริง

| | |
|---|---|
| `dotnet run` **ไม่ hot-reload** service/state machine | แก้โค้ดแล้วไม่ restart = เข้าใจผิดว่าโค้ดไม่ทำงาน เคยหลงมาหลายรอบ |
| ต้องต่อ **Garage Pro VPN** ก่อนเสมอ | `scutil --nc start "Garage Pro VPN"` — ไม่ต่อ = เข้าฐานไม่ได้เลย |
| `<img src>` กับ endpoint ที่ต้อง Bearer | ใช้ไม่ได้ ต้อง fetch เป็น blob — ทั้งเว็บและ Flutter เจ็บมาแล้วทั้งคู่ |
| Dart: ใช้ `List` เป็น family key ของ Riverpod | เทียบด้วย identity ⇒ ยิง API ไม่หยุด ใช้สตริงที่เรียงแล้วแทน |
| Guid PK ต้อง `ValueGeneratedNever()` | ไม่งั้น EF ยิง UPDATE แทน INSERT |
| ตัวเลขเวลา/เงินต้องใช้ฟอนต์ tabular | ไม่งั้นแถบนาฬิกาสั่นทั้งแถบทุกวินาที |
| deploy โดยไม่ใส่ `SELFSERVE_ENABLED=true` | หลังเปิดรับสมัครแล้ว deploy รอบไหนลืมใส่ ระบบปิดรับสมัครเองเงียบๆ |
| รัน `deploy-production.sh` จาก checkout ที่ตามหลัง main | สคริปต์ rsync `deploy/production` จากเครื่องที่รันด้วย `--delete` จะเอาไฟล์รุ่นเก่าขึ้นไปทับ (checkout หลักบน Mac ตามหลังอยู่) |
| `bootstrap-production-secrets.sh` เขียนทับ env file ทั้งไฟล์ | ค่าที่ไม่อยู่ใน user-secrets บน Mac หายจาก server (เคยลบค่า LINE ไปแล้วครั้งหนึ่ง) · สำรองไฟล์ก่อนรันทุกครั้ง |
| `provision-selfserve-db.sh` | ต้องใช้ go-sqlcmd (`PATH="/opt/homebrew/opt/sqlcmd/bin:$PATH"`) · ช่องรหัส login ต้องพิมพ์รหัสจริง เพราะ smoke test ใช้ login ด้วยรหัสนั้น |
| คำสั่ง `read -p` ใน zsh | zsh ตีความเป็น coprocess ใช้ `printf "...: " && read -rs K` แทน |

รายการเต็ม (พร้อมอาการและวิธีแก้) อยู่ที่ CLAUDE.md หัวข้อ **"บทเรียนที่เจ็บมาแล้ว"**
