# บทนำเสนอ ServicePro ทดลองใช้ด้วยตัวเอง (~15 นาที + ถาม-ตอบ)

ใช้คู่กับคู่มือเตรียมเครื่องและขั้นตอนกด [docs/13-selfserve-manual-test.md](13-selfserve-manual-test.md)

## เตรียมก่อนขึ้นพูด

- เปิด API + เว็บ (ดู docs/13) · simulator ล็อกอินเป็นช่างค้างไว้ · terminal ของ API เปิดไว้ดู OTP
- เตรียมอีเมลใหม่ที่ยังไม่เคยสมัคร 1 อัน (ใช้ซ้ำไม่ได้) · เปิด terminal ของ `spadmin` ไว้อีกแท็บ
- รีสตาร์ต API ก่อนเริ่ม 1 ครั้ง (ล้างลิมิตสมัคร 3 ครั้ง/ชม.)
- เปิดแท็บสำรอง: อู่ที่สมัครไว้แล้ว เผื่อขั้นสมัครสดมีปัญหา

## คำถามที่น่าจะโดนถาม

| คำถาม | ตอบ |
|---|---|
| ลูกค้าจ่ายเงินแล้วข้อมูลที่ลองไว้หายไหม | ย้ายข้อมูลหลัก (ลูกค้า รถ สินค้า เทมเพลต พนักงาน) เข้าสาขา GaragePro จริงได้ จ๊อบ/ใบเสนอราคา/ใบเสร็จช่วงทดลองไม่ย้าย |
| สมัครซ้ำเพื่อใช้ฟรีต่อได้ไหม | อีเมลเดียวสมัครได้ครั้งเดียวตลอดไป Gmail ที่เติมจุดหรือ `+` นับเป็นอีเมลเดิม เบอร์ซ้ำระบบติดธงให้ทีมขายเห็น |
| อีเมลปลอม/บอทสมัครเยอะจะทำยังไง | ต้องยืนยันรหัสทางอีเมล บล็อกอีเมลชั่วคราว ตรวจโดเมนว่ารับอีเมลได้จริง มี Turnstile และจำกัดจำนวนครั้งต่อเครื่อง |
| กระทบลูกค้าเดิมไหม | ไม่กระทบ ฐานข้อมูลแยก เมนู/สิทธิ์ของลูกค้าเดิมเหมือนเดิมทุกอย่าง |
| แอปมือถือต้องอัปเดตไหม | แอปบน store ล็อกอินได้เลย รุ่นถัดไปเพิ่มแถบบอกวันที่เหลือ |
| ทีมขายรู้ได้ยังไงว่ามีคนสมัคร | แจ้งเข้ากลุ่ม LINE ทุกครั้งที่สมัคร/ขอต่ออายุ และสรุปรายวัน 08:30 |

## ถ้า demo สะดุด

- **OTP ไม่ขึ้น:** ดูใน terminal ของ API บรรทัด `[email:log]`
- **สมัครไม่ได้ "ส่งคำขอถี่เกินไป":** รีสตาร์ต API แล้วลองใหม่
- **ขั้นใดไม่ไปต่อ:** สลับไปแท็บอู่ที่สมัครไว้แล้ว แล้วเล่าต่อจากขั้นนั้น
