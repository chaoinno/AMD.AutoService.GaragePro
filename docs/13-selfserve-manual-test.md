# ซ้อมทดสอบ/นำเสนอ ServicePro ทดลองใช้ (เครื่อง dev)

ใช้ branch `feat/sp1-selfserve` (worktree `.claude/worktrees/integration`) กับฐาน `GarageSelfServe_Dev` ที่เตรียมไว้แล้ว

## 1. เตรียมเครื่อง (ก่อนเริ่ม 5 นาที)

1. ต่อ VPN: `scutil --nc start "Garage Pro VPN"`
2. ปิด API/เว็บของ main checkout ก่อน (ใช้พอร์ต 5080/5173 เดียวกัน)
3. เปิด API แล้ว**เปิด terminal นี้ค้างไว้ รหัส OTP จะขึ้นที่นี่** (ยังไม่มีผู้ให้บริการอีเมลจริง)
   ```
   cd .claude/worktrees/integration
   dotnet run --project backend/AMD.AutoService.GaragePro.API
   ```
4. เปิดเว็บอีก terminal แล้วเข้า http://localhost:5173
   ```
   cd .claude/worktrees/integration/web
   node_modules/.bin/vite --port 5173
   ```

## 2. ข้อมูลที่ต้องใช้

| รายการ | ค่า |
|---|---|
| อีเมลเจ้าของอู่ | อีเมลจริงที่**ยังไม่เคยใช้สมัคร** ใช้แล้วใช้ซ้ำไม่ได้ตลอดไป แม้ลบอู่แล้ว · Gmail ตัด `.` และ `+tag` ทิ้ง (`a.b+1@gmail.com` = `ab@gmail.com`) · โดเมนอื่นใช้ `+demo1`, `+demo2` แยกกันได้ |
| รหัสผ่าน | 8 ตัวขึ้นไป มีทั้งตัวอักษรและตัวเลข |
| รหัส OTP | ใน terminal ของ API บรรทัด `[email:log] … รหัสยืนยันอีเมล ServicePro: 123456` |
| ชื่ออู่ / เบอร์โทร | อะไรก็ได้ · เบอร์ขึ้นต้น 06/08/09 ครบ 10 หลัก |
| รหัสอู่ | ได้หลังสมัคร เช่น `SP1007` ใช้กับคำสั่ง spadmin ด้านล่าง |
| บัญชีช่างตัวอย่าง | `SP1007.T01` / `SP1007.T02` รหัสผ่านโชว์บนการ์ดหน้าจ๊อบ **ครั้งเดียว** จดไว้ก่อนกดซ่อน |

**ข้อจำกัดตอนนี้:** ไม่มีปุ่ม Google (ยังไม่มี client id) · ไม่มี LINE แจ้งทีมขาย · สมัครได้ 3 ครั้ง/ชม./เครื่อง (เกิน → รีสตาร์ต API) ·
แอปบน store ชี้ production จึงลองกับเครื่อง local ไม่ได้ (ใช้หน้าต่าง private ล็อกอินเป็นช่างแทน)

## 3. ลำดับนำเสนอ (~10 นาที)

| # | ทำ | ควรเห็น |
|---|---|---|
| 1 | เปิด `/` → กด "ทดลองใช้ฟรี" | หน้าสมัคร 3 ขั้น |
| 2 | กรอกอีเมล + รหัสผ่าน ติ๊กยอมรับ → "รับรหัสยืนยันทางอีเมล" | ขั้น "ยืนยันอีเมล" |
| 3 | ใส่ OTP จาก terminal | ขั้น "ตั้งค่าอู่" |
| 4 | ชื่ออู่ + เบอร์ (จังหวัด/ขนาดไม่บังคับ) · ติ๊ก "ใส่ข้อมูลตัวอย่าง" → "เริ่มใช้งาน ServicePro" | รอ 5–10 วิ แล้วเข้าหน้าจ๊อบ: แถบ "ทดลองใช้ · เหลือ 30 วัน" · การ์ด "เริ่มใช้ใน 5 ขั้น" · รหัสช่างตัวอย่าง · จ๊อบตัวอย่าง 2 คัน |
| 4.1 | หน้าจ๊อบ → "เปิดจ๊อบ" → กด "ใช้ลูกค้าตัวอย่าง" → เลือก **คุณวิชัย มาใหม่** และรถ 3กค 9012 → ใส่เลขไมล์ → เปิดจ๊อบ | จ๊อบใหม่สถานะ "รอตรวจเช็ค" · เช็คลิสต์ขั้น "เปิดจ๊อบแรก" ติ๊ก (ลูกค้าอีก 2 คนมีงานค้างอยู่ เลือกแล้วจะขึ้นเตือน) |
| 5 | เปิดจ๊อบตัวอย่าง → ขั้นเสนอราคา → ดูเอกสาร/พิมพ์ | ลายน้ำ "ทดลองใช้" + บรรทัดท้ายกระดาษ |
| 6 | กดเมนูที่มีรูปกุญแจ (PR/PO · สต็อก · POS · รายงานขั้นสูง) | หน้า "…เปิดในแพ็กเกจเต็ม" + ปุ่มติดต่อเรา |
| 7 | เมนูพนักงาน → "เพิ่มพนักงาน" (ชื่อ · บทบาท "ช่าง") | หน้าต่างรหัสเข้าแอป `SP1007.T03` + QR Google Play · เช็คลิสต์ขั้น "เพิ่มช่าง" ติ๊กเอง |
| 8 | (ทางเลือก) หน้าต่าง private → เข้าสู่ระบบด้วย `SP1007.T03` | เข้าได้ในบทบาทช่าง |
| 9 | (ทางเลือก) เพิ่มพนักงานจนเกิน 5 คน (นับเจ้าของ + ช่างตัวอย่าง) | ข้อความ "ครบจำนวนที่แพ็กเกจทดลองใช้รองรับแล้ว (พนักงาน สูงสุด 5)" |

## 4. จำลองสถานะแพ็กเกจ (spadmin)

```
cd .claude/worktrees/integration/tools/spadmin
export DOTNET_ENVIRONMENT=Development
dotnet run -- show --workspace SP1007
```

| จำลอง | คำสั่ง (`dotnet run -- …`) | ควรเห็น (รอ ~1 นาทีแล้วรีเฟรช) |
|---|---|---|
| หมดอายุ | `extend --workspace SP1007 --days -31` | ถูกพากลับหน้าเข้าสู่ระบบพร้อมเหตุผล → เข้าใหม่: แถบแดง "ครบ 30 วันแล้ว" · ดูได้ แก้ไม่ได้ · ปุ่ม "ขอต่ออายุ" |
| คืนค่า | `extend --workspace SP1007 --days 31` | กลับเป็นทดลองใช้ปกติ |
| จ่ายเงินแล้ว | `set-plan --workspace SP1007 --plan paid --until 2027-12-31` | เข้าใหม่แล้วกุญแจหายทุกเมนู · ไม่มีแถบทดลองใช้/ลายน้ำ |
| ระงับ | `set-plan --workspace SP1007 --plan suspended` | เข้าสู่ระบบไม่ได้ ข้อความให้ติดต่อ LINE @garagepro |
| กลับเป็นทดลองใช้ | `set-plan --workspace SP1007 --plan trial --until <วันหมดอายุเดิมจาก show>` | ใช้งานต่อได้ |

## 5. เก็บกวาดหลังซ้อม

```
dotnet run -- purge --workspace SP1007 --yes
```
